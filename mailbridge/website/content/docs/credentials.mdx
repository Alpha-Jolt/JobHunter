## Supported providers

| Provider | Auth method | Setup |
|---|---|---|
| Gmail | OAuth 2.0 | Requires Google Cloud project |
| Outlook | OAuth 2.0 | Requires Azure AD app |
| SMTP | Username + password | Any SMTP server |

## Add SMTP credential

```http
POST /api/credentials/smtp
Authorization: Bearer TOKEN
Content-Type: application/json

{
  "from_email": "noreply@acme.com",
  "host": "smtp.acme.com",
  "port": 587,
  "secure": false,
  "user": "noreply@acme.com",
  "pass": "smtp-password"
}
```

## Connect Gmail via OAuth

```http
GET /api/credentials/gmail/connect
Authorization: Bearer TOKEN
```

Returns a redirect URL. Send the user to this URL to complete OAuth consent.

## Connect Outlook via OAuth

```http
GET /api/credentials/outlook/connect
Authorization: Bearer TOKEN
```

## Test a credential

```http
POST /api/credentials/:id/test
Authorization: Bearer TOKEN
```

Sends a test connection to verify the credential is valid.

## Security

All credentials are encrypted with AES-256-GCM before storage. The master key (`CREDENTIAL_MASTER_KEY`) is never stored in the database — only the encrypted ciphertext and IV.
